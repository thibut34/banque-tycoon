# 🏦 Banque Tycoon

Un simulateur de banque jouable dans le navigateur (ordinateur et mobile).

**▶ Jouer : https://thibut34.github.io/banque-tycoon/**

## Le principe

Vous dirigez une petite banque. Objectif : atteindre **50 M€ de fonds propres** sans faire faillite… puis viser la Lune 🌕.

- 💰 **Dépôts** : fixez le taux de rémunération et les frais pour attirer les épargnants.
- 🤝 **Prêts** : étudiez chaque demande (note A→E, montant, durée) et choisissez votre taux. Trop cher, le client part ; trop risqué, il ne rembourse pas.
- 📈 **Marchés** : obligations, CAC 40, actions tech, pétrole, or, l'action mème « Escargots & Co » et la crypto BitBaguette.
- 🏛️ **Banque centrale** : empruntez au taux directeur, qui suit la conjoncture.
- 🌪️ **Cycles économiques** : croissance, stabilité, récession, crise (défauts ×3, krach boursier).
- ⚖️ **Régulateur** : gardez un ratio de solvabilité ≥ 8 %, sinon surveillance puis retrait de licence.
- 🏢 **Agences** : de Montpellier à New York… jusqu'à la base lunaire.
- ⚙️ **Améliorations** : analyste crédit, IA de scoring, cybersécurité, lobbyiste, ordinateur quantique…
- 🎲 **Événements** : cyberattaques, braquages, la mafia, stars, bugs à 1 milliard, start-ups licornes, extraterrestres…
- 😎 **Vous** : versez-vous des bonus et achetez yacht, jet ou île privée.
- 🏆 Succès, meilleurs scores et sauvegarde automatique.

**Espace** = pause · **Échap** = menu.

Fait en HTML/CSS/JavaScript, sans aucune dépendance.
